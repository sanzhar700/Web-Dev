# Python OOP Project – Animal Hierarchy

This project demonstrates Object-Oriented Programming concepts in Python.

## Classes

### Animal (Base Class)

Attributes:
- name
- age
- color

Methods:
- speak()
- move()
- info()
- __str__()

### Dog (Child Class)

Additional attribute:
- breed

Methods:
- speak() (overridden)
- fetch()

### Cat (Child Class)

Additional attribute:
- indoor

Methods:
- speak() (overridden)
- scratch()

## OOP Concepts Demonstrated

- Classes and Objects
- Constructors (`__init__`)
- Inheritance
- Method Overriding
- Polymorphism
- Modules and Imports
